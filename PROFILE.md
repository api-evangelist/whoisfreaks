## APIs

- **WhoisFreaks API** — REST API (JSON/XML) for Live WHOIS, WHOIS History, Bulk/Reverse WHOIS, IP/ASN WHOIS, DNS, Domain Availability, IP Geolocation, IP Security, SSL, and Subdomains. API-key authenticated via query parameter. (`https://api.whoisfreaks.com/v2.0/`)

> REST API is JSON/XML, API-key (query param) authenticated at https://api.whoisfreaks.com/v2.0/ (v1.0 legacy). A public Postman collection serves as the closest machine-readable contract; no OpenAPI/AsyncAPI/GraphQL spec was found. An llms.txt is published at https://whoisfreaks.com/llms.txt. An official open-source MCP server exists (github.com/whoisfreaks/whoisfreaks-mcp-server, Docker image whoisfreaks/mcp-server) exposing ~14 tools; however its HTTP/SSE transport is documented only at http://localhost:3100/sse (local/self-hosted, not a hosted public endpoint), so it is NOT cataloged as an MCP property. WhoisFreaks also ships an MS Security Copilot plugin and a Make integration. No published agent skills found.
