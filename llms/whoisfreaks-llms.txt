## API Pages

- [Whois API](https://whoisfreaks.com/products/whois-api): Retrieve WHOIS records and detailed domain registration data.
- [Whois History API](https://whoisfreaks.com/products/whois-history-api): Access historical WHOIS records to track past domain ownership and registration changes over time.
- [Bulk Whois API](https://whoisfreaks.com/products/bulk-whois-api): Perform bulk WHOIS queries for multiple domains simultaneously for efficient data retrieval.
- [Reverse Whois API](https://whoisfreaks.com/products/reverse-whois-api): Returns every domain registered to a given email, registrant name, organization, or 3 to 63 character domain keyword, across 4.1B+ current and historical WHOIS records dating back to 1986. Regex supported on email, exact match on keyword, owner, and company. Paginated at 50 records per page or 100 in mini mode, JSON or XML, 10 requests per minute, 500 free credits on signup. Used for threat actor infrastructure pivots, cybersquatting discovery, M&A due diligence, and CRM enrichment. For a single browser search use the Reverse WHOIS Lookup tool; for ongoing daily alerts on a registrant use Registrant Monitoring.
- [DNS Checker API](https://whoisfreaks.com/products/dns-checker-api): Check and validate DNS records across global resolvers.
- [Domain Availability API](https://whoisfreaks.com/products/domain-availability-api): Verify domain name availability in real time.
- [IP Geolocation API](https://whoisfreaks.com/products/ip-geolocation-api): Get geographic location and network details for IP addresses.
- [IP Reputation API](https://whoisfreaks.com/products/ip-security-api): Detect proxies, VPNs, bots, and malicious IP activity.
- [SSL Certificate API](https://whoisfreaks.com/products/ssl-certificate-api): Fetch SSL certificate details and validation information.
- [Subdomain API](https://whoisfreaks.com/products/subdomains-api): Discover and enumerate subdomains for a given domain.
- [ASN Whois API](https://whoisfreaks.com/products/asn-whois-api): Access WHOIS information for Autonomous System Numbers (ASNs) via API.
- [IP Whois API](https://whoisfreaks.com/products/ip-whois-api): Retrieve WHOIS and registration details for IP addresses programmatically.

## Monitoring Pages

- [Brand Monitoring](https://whoisfreaks.com/products/brand-monitoring): Domain brand monitoring across 1528+ TLDs. Twice-daily scans detect lookalikes, typosquats, homoglyphs, and unauthorized trademark registrations with full WHOIS records per alert. Used by IP teams for UDRP evidence, security teams for phishing takedown, and marketing teams for brand protection.
- [Domain Monitoring](https://whoisfreaks.com/products/domain-monitoring): WHOIS-record monitoring for any domain across 1528+ TLDs. Checks as frequent as every 10 minutes detect changes to registrant, registrar, nameservers, status codes, and expiry. Email and Telegram alerts. Used by security teams for hijack detection, domain owners for unauthorized-modification alerts, and domain investors for drop and re-registration tracking. Does not monitor HTTP uptime or DNS health.
- [Registrant Monitoring](https://whoisfreaks.com/products/registrant-monitoring): Daily alerts on every new domain registered, updated, or dropped by a name, email, organization, phone, or postal code across 1528+ TLDs. Full WHOIS record per alert, by email and as JSON. Used by security teams for threat actor attribution and OSINT, brand teams for cybersquatting, legal teams for UDRP and trademark evidence, and competitive intelligence teams. Does not monitor a single domain (use Domain Monitoring) or run one-time lookups (use Reverse WHOIS API).
